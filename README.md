# Data Engineering Interview Prep Portal — Supabase Edition

This version stores all portal data in Supabase PostgreSQL. On startup, the app connects to Supabase and automatically creates the required tables if they do not exist.

## 1. Create a Supabase project

1. Create a project at https://supabase.com/dashboard.
2. Open **Project Settings → Database** and locate the PostgreSQL connection string.
3. Prefer the **Session Pooler** connection string if your hosting environment cannot connect directly to the database host (for example, IPv6 limitations).
4. Keep the password private. If the password contains URL-reserved characters, use the connection URI generated by Supabase or URL-encode the password.

## 2. Configure locally on Windows

From PowerShell in this project folder:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
New-Item -ItemType Directory -Force .streamlit
Copy-Item .streamlit\secrets.toml.example .streamlit\secrets.toml
```

Edit `.streamlit/secrets.toml` and replace the sample value with your actual Supabase PostgreSQL connection string. Do not share or commit this file.

Then run:

```powershell
python -m streamlit run app.py
```

The app creates `users`, `questions`, `progress`, `sessions`, and `announcements` tables automatically. On the first run, create the first administrator in the app. Then use **Admin: Users** to add learners.

## 3. Deploy to Streamlit Community Cloud

1. Push the project files to a GitHub repository. Do not include `.streamlit/secrets.toml` or any database password.
2. Deploy `app.py` at https://share.streamlit.io/.
3. In the app's **Settings → Secrets**, add:

```toml
SUPABASE_DB_URL = "postgresql://...your real Supabase connection string..."
```

4. Reboot the app. The app will connect to Supabase and initialize its tables automatically.

## Important security notes

- `SUPABASE_DB_URL` is a server-side database credential. Never put it in frontend code, public source files, screenshots, or a committed `.env` / `secrets.toml` file.
- This starter app uses its own admin-managed username/password table. Passwords are stored as PBKDF2 hashes, not plaintext. Before a wide public launch, add password change/reset, login rate limiting, and stronger session handling, or migrate authentication to Supabase Auth.
- Because this version connects directly from the server-side Streamlit app, keep the database connection string secret and do not use it in any client/browser code. For a larger production system, create a least-privilege database role rather than using a database owner credential.
- The app creates tables automatically using the configured database role. If that role does not have DDL permissions, table initialization will fail; initialize schema through Supabase SQL Editor or use a separate migration role.
- The free tier may pause inactive projects and does not provide the same backup guarantees as paid plans. Schedule independent encrypted exports and test restoration.
- Do not rely on a local SQLite file for production persistence; this edition uses Supabase PostgreSQL.

## Tables created

- `users`: admin and learner accounts
- `questions`: daily interview questions
- `progress`: per-learner status and private notes
- `sessions`: upcoming/past study sessions
- `announcements`: admin announcements
